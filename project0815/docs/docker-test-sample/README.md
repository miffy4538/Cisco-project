# Dockerの練習用サンプル（未使用）

`Dockerfile` と `index.html` は、Dockerの使い方を試すために作った最初期の
練習用サンプルです。`index.html` の中身も「Dockerの世界へようこそ」という
単なるテストページで、このアプリ（見守りシステム）の一部ではありません。

実際のデプロイでは、リポジトリ直下の `docker-compose.yml` が
`server/Dockerfile` と `client/Dockerfile` を使ってビルド・起動します。
このフォルダの2ファイルはどちらのビルドにも使われていません。

削除しても実際の動作には影響しませんが、練習の記録として参考用に残しています。
